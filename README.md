# 🚌 Busora — Bus Ticket Booking Website

Busora is a modern, responsive bus ticket booking website built with React, Vite, and Tailwind CSS. It provides an intuitive interface for exploring destinations, searching bus routes, selecting seats, and moving through a demo ticket booking process.

## ✨ Features

- **Responsive Navbar** — Easy navigation across the website.
- **Hero Section** — Attractive landing page with a bus search interface.
- **Bus Search** — Search routes by departure city, destination, and travel date.
- **Popular Destinations** — Explore destinations with image cards and hover animations.
- **Bus Listings** — Browse available sample bus options.
- **Bus Details** — View journey information and available seat options.
- **Seat Selection** — Interactive seat selection interface.
- **Passenger Details** — Enter passenger information.
- **Booking Confirmation** — Review the demo booking summary.
- **Login & Signup** — Authentication interface pages.
- **Booking History** — View demo booking information, if configured in the project.
- **About Section** — Learn about Busora and its features.
- **Customer Reviews** — Display sample customer feedback.
- **Scroll Animations** — Reveal effects, staggered cards, and smooth transitions.
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- React Router DOM
- Lucide React Icons
